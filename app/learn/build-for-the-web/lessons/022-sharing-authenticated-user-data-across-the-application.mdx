#### Current Loader

```ts
export async function loader({ request }: Route.LoaderArgs) {
	const userId = await requireUserId(request)

	const user = await requireUser(request)

	const messages = await prisma.message.findMany({
		where: { userId },
		orderBy: { createdAt: 'asc' },
	})

	let profile = await prisma.profile.findUnique({
		where: { userId },
	})

	if (!profile) {
		profile = await prisma.profile.create({
			data: {
				userId,
				isFollowing: false,
			},
		})
	}

	return { user, messages, profile }
}
```

#### Then Add a Root Loader

```tsx
export async function loader({
	request,
}: Route.LoaderArgs) {
	const userId = await getCurrentUserId(request)

	if (!userId) {
		return {
			user: null,
		}
	}

	const user = await requireUser(request)

	return {
		user,
	}
}
```

#### Important

- The root route now:

  - loads authenticated users
  - provides shared authenticated application data

#### Important

- The root loader uses:

```ts
getCurrentUserId(request)
```

```ts
requireUserId(request)
```

#### Why?

- Because:
  - public routes still exist
  - unauthenticated users may still visit the application

#### Example

#### Reality

```text
The root route must support both authenticated and unauthenticated
application states
```

## Step 7: Use the Shared Data 🔄

- Inside:

```text
app/root.tsx
```

#### Current Imports

```tsx
import {
	isRouteErrorResponse,
	Links,
	Meta,
	Outlet,
	Scripts,
	ScrollRestoration,
} from 'react-router'
```

#### Add

```tsx
useLoaderData
```

#### Updated Imports

```
import {
	isRouteErrorResponse,
	Links,
	Meta,
	Outlet,
	Scripts,
	ScrollRestoration,
	useLoaderData,
} from 'react-router'
```

#### Then Update the Layout Component

```tsx
export function Layout({
	children,
}: {
	children: React.ReactNode
}) {
	const { user } = useLoaderData<typeof loader>()

	return (
		<html lang='en'>
			<head>
				<meta charSet='utf-8' />

				<meta
					name='viewport'
					content='width=device-width, initial-scale=1'
				/>

				<Meta />

				<Links />
			</head>

			<body>
				<header>
					{user ? (
						<p>
							Welcome back, {user.name}
						</p>
					) : (
						<p>
							Welcome to the application
						</p>
					)}
				</header>

				{children}

				<ScrollRestoration />

				<Scripts />
			</body>
		</html>
	)
}
```

#### Important

- `useLoaderData()` works here because:
  - the loader exists inside `app/root.tsx`
  - the layout belongs to the root route
  - the layout and loader belong to the same route module
  - the root route owns the shared authenticated data

#### Mental Model

```text
loader()
  → Creates route data

useLoaderData()
  → Reads route data
```

#### Important

- The layout does NOT import loaders from child routes.

#### Example

```tsx
import { loader } from './routes/home'
```

#### This would be incorrect because:

```text
Parent routes should not depend on child route loaders
```

#### Reality

```text
Route hierarchy flows downward through parent routes
```

#### Important

- The shared authenticated UI now lives inside:

```text
Layout()
```

#### Instead of:

```text
App()
```

#### Why?

- Because the layout already controls:
  - the application shell
  - shared application structure
  - global application UI
  - shared rendering boundaries

#### Important

- The `App()` component still remains simple:

```tsx
export default function App() {
	return <Outlet />
}
```

#### Mental Model

```text
Layout()
  → Shared authenticated application UI

App()
  → Route rendering
```

#### Reality

```text
The application shell now understands authenticated state
```

> Shared layouts naturally become shared authenticated architecture
