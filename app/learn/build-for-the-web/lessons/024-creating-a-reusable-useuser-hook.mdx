## Step 4: Create the Hook ⚡

#### Inside

```text
app/hooks/useUser.ts
```

#### Add

```tsx
import { useRouteLoaderData } from 'react-router'

export function useUser() {
	const rootData =
		useRouteLoaderData('root')

	return rootData?.user
}
```

#### Important

- The hook now:
  - accesses the root route
  - retrieves root data
  - returns the authenticated user

#### Reality

```text
The implementation is now centralized
```

> One hook can replace many repeated code blocks
