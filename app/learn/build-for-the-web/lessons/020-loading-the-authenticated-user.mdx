## Step 1: Observe the Current Authentication Flow 🔍


#### Loader

```ts
export async function loader({ request }: Route.LoaderArgs) {
	const userId = await requireUserId(request)

	const messages = await prisma.message.findMany({
		where: { userId },
		orderBy: { createdAt: 'asc' },
	})

	let profile = await prisma.profile.findUnique({
		where: { userId },
	})

	if (!profile) {
		profile = await prisma.profile.create({
			data: {
				userId,
				isFollowing: false,
			},
		})
	}

	return { messages, profile }
}
```

## Step 5: Create a Database Migration ⚡

- The Prisma schema has now changed.

#### Important

- The actual database must also change.

#### Why this matters

- Updating `schema.prisma` alone does NOT update:
  - the database
  - the Prisma client

#### Reality

```text
Schema file
  → Defines intended structure

Migration
  → Updates database structure

Prisma Client
  → Updates generated database types
```

#### Run the Migration

```text
npx prisma migrate dev --name expand-user-model
```

#### What this does

- Prisma will:
  - detect schema changes
  - generate a migration
  - update the SQLite database

#### But one more step still matters.

- Regenerate the Prisma Client

```bash
npx prisma generate
```

#### Why this matters

- The generated Prisma client must understand:
  - new fields
  - updated models
  - updated database types

- Without regeneration:
  - TypeScript may not recognize new fields
  - Prisma queries may show type errors

#### Add User Loading

```ts
export async function loader({ request }: Route.LoaderArgs) {
	const userId = await requireUserId(request)

	const user = await prisma.user.findUnique({
		where: { id: userId },
	})

	const messages = await prisma.message.findMany({
		where: { userId },
		orderBy: { createdAt: 'asc' },
	})

	let profile = await prisma.profile.findUnique({
		where: { userId },
	})

	if (!profile) {
		profile = await prisma.profile.create({
			data: {
				userId,
				isFollowing: false,
			},
		})
	}

	return { user, messages, profile }
}
```

#### What changed

- The route now:
  - authenticates the request
  - loads authenticated identity
  - loads authenticated user data

#### System Flow

```text
Request
  → Session
  → userId
  → User Lookup
  → Authenticated User
```

#### Important

```text
Identity is now becoming usable application information
```

> Authentication now powers application behavior
