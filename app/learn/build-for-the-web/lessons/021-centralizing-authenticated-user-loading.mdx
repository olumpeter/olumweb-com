## Step 1: Observe the Current User Loading Flow 🔍

- Open:

```text
app/routes/home.tsx
```

#### Current Loader

```ts
export async function loader({ request }: Route.LoaderArgs) {
	const userId = await requireUserId(request)

	const user = await prisma.user.findUnique({
		where: { id: userId },
	})

	const messages = await prisma.message.findMany({
		where: { userId },
		orderBy: { createdAt: 'asc' },
	})

	let profile = await prisma.profile.findUnique({
		where: { userId },
	})

	if (!profile) {
		profile = await prisma.profile.create({
			data: {
				userId,
				isFollowing: false,
			},
		})
	}

	return { user, messages, profile }
}
```

## Step 5: Add a Reusable Authenticated User Loader ⚡

- Inside:

```text
app/data/auth.server.ts
```

- Add:

```ts
import { prisma } from '~/data/prisma.server'

export async function requireUser(request: Request) {
	const userId = await requireUserId(request)

	const user = await prisma.user.findUnique({
		where: { id: userId },
	})

	if (!user) {
		throw redirect('/login')
	}

	return user
}
```

#### Important

- The authentication system already had:

```text
getCurrentUserId()
  → Reads authenticated identity

requireUserId()
  → Enforces authenticated access
```

#### Now the system also has:

```text
requireUser()
  → Loads authenticated users
```

#### System Evolution

```text
Session Reading
  → Authentication Enforcement
  → Authenticated User Loading
```

#### What `requireUser()` does

- The utility now:
  - verifies authenticated access
  - loads authenticated user data
  - guarantees authenticated users exist

#### Example

```text
Authenticated session exists
BUT
Database user no longer exists
```

#### Reality

- This can theoretically happen if:
  - the database resets
  - users are deleted manually
  - orphaned sessions still exist

#### Important

```text
Authenticated identity must map to a real database user
```

#### Example

```ts
if (!user) {
	throw redirect('/login')
}
```

#### Reality

```text
Protected routes should never receive invalid authenticated users
```

#### Mental Model

```text
getCurrentUserId()
  → Reads identity

requireUserId()
  → Protects identity

requireUser()
  → Loads authenticated application users
```

> Authentication abstractions are evolving layer by layer
